# Python Expense Tracker

A simple command-line Expense Tracker built using Python. It allows users to record expenses, view all saved expenses, and calculate their total spending.

## Features

- Add expenses with date, category, description, and amount.
- View all recorded expenses.
- Calculate total expenses.
- Interactive menu-driven interface.
- Store expense records using Python lists and dictionaries.

## Technologies Used

- Python 3
- Lists and Dictionaries
- Loops and Conditional Statements
- User Input and Output

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python expense_tracker.py
```

On some systems, use `python3` instead of `python`.

## Current Limitations

Expenses are stored in memory, so records are lost when the program exits. Persistent storage is not currently implemented.

## Learning Outcomes

This project demonstrates basic Python programming, data storage using lists and dictionaries, user input handling, and menu-driven program design.
